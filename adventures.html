Frequently Asked Questions

What do I get when I buy an adventure?

Every adventure includes the full PDF, VTT-ready battle maps for Roll20 and Foundry, a character token sheet, and a print-ready version — everything you need to prep and run the session.

What tabletop system are these built for?

Every adventure on Crits & Crafts is built for 5th Edition D&D and designed as a self-contained one-shot — no ongoing campaign or extra source material required.

How long does a session take to run?

Most one-shots are built to run start to finish in a single 3–4 hour sitting, so you can fit a whole story into one session.

Can I run these online or in person?

Both. Each adventure comes with VTT-ready maps for online play, plus a print-ready version for tables that still roll physical dice.

How do I get my files after I buy?

Checkout is handled through Lemon Squeezy — after purchase, you'll get a download link by email.
